# 治愈系心情日记网站｜Web前端结课作业
## 项目介绍
使用 HTML5+CSS3+原生JavaScript开发，莫兰迪治愈极简风格，4个页面，满足课程全部评分规范：语义化标签、Flex/Grid双布局、表单/列表/表格/超链接全覆盖、CSS动画+JS交互、移动端自适应。

## 目录结构
diary-space/
├── index.html        首页：心情打卡+语录轮播
├── diary.html        日记合集：Grid卡片+心情筛选
├── mood.html         心情统计：表格+JS自动计数
├── message-board.html留言板：DOM动态增删留言
├── css/style.css     全局样式、动画、响应式
├── js/main.js        全部交互逻辑、本地存储localStorage
└── images            素材文件夹（可选放背景图）

## 技术亮点
1. HTML5：header/main/footer/section/article 全语义化标签
2. CSS：Flex导航+Grid卡片布局、动态背景渐变动画、hover悬停效果、媒体查询移动端适配
3. JS：自动轮播、表单提交、localStorage本地持久化、下拉筛选、数据统计计算、DOM动态创建/删除元素
4. 页面元素：form表单、ul列表、table表格、a超链接全部使用，符合课程要求

## 使用方法
直接打开index.html即可运行，无需服务器，数据自动保存在浏览器本地。
